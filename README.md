# UMKM Pamflet Maker V3 — Automatic Layout

Versi ini memprioritaskan pembuatan pamflet.

## Alur pengguna
1. Masukkan nama produk, promosi, harga, WhatsApp, dan foto.
2. Klik "Buatkan Pamflet Otomatis".
3. Sistem melakukan analisis rule-based sederhana.
4. Sistem memilih layout berdasarkan jenis produk/kata kunci.
5. Sistem membuat 3 alternatif desain.
6. Pengguna memilih satu.
7. Download PNG atau bagikan.

## Catatan penting
"Smart Layout Engine" pada V3 ini adalah rule-based, bukan AI cloud. Tidak membutuhkan API dan dapat berjalan sepenuhnya di GitHub Pages. AI sungguhan dapat ditambahkan kemudian untuk copywriting, klasifikasi foto, background removal, dan rekomendasi layout.

## Deploy
Upload/replace `index.html`, `style.css`, `script.js`, `manifest.json` ke root repository GitHub Pages.
