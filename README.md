# UMKM Design Maker — Mobile First

Versi mobile-first untuk GitHub Pages.

## Fitur
- UI dirancang untuk layar HP
- 3 langkah: Input → Template → Selesai
- Upload foto dari galeri
- 5 template
- Preview 4:5 1080×1350
- Download PNG
- Share sheet via Web Share API
- Tombol WhatsApp
- PWA manifest dasar
- Tidak membutuhkan backend

## Deploy
Upload semua file ke repository GitHub, lalu aktifkan GitHub Pages dari Settings → Pages → Deploy from branch → `main` → `/root`.

## Catatan
Versi ini adalah MVP. Fitur AI sebenarnya seperti auto-copywriting, background removal, dan rekomendasi layout memerlukan API/backend atau layanan AI.
